# 유스케이스 명세
**유스케이스 이름 :** FC 안양 길찾기
**관련 액터 :** 축구 관중
**시작 조건 :** 사용자가 모바일 웹페이지에 접속되어 있어야 한다.
**기본 흐름**
1. 메인 화면의 드롭다운에서 자신의 좌석 권종과 세부 좌석 위치를 선택하고 출발지를 X배너 위치로 선택하고 검색 버튼을 누른다.
2. 시스템은 출발지와 도착지 간의 최적 경로 데이터를 호출한다.
3. 시스템은 화면을 단계별 사진 안내를 나타내도록 전환한다.
4. 시스템은 화면에 실제 현장 사진을 띄우고, 사진 위에 게이트 방향을 가리키는 화살표를 오버레이한다. 하단에는 길찾기를 돕는 안내 텍스트를 표시한다.
5. 사용자가 지시된 방향대로 이동한 후, 화면을 스와이프하거나 '다음' 버튼을 누른다.
6. 그 다음 위치의 사진이 뜨고 마찬가지로 화살표와 텍스트를 통해 길찾기를 돕는다.
7. 목적지에 도달할 때까지 4~6 과정을 반복한다.

**대안 흐름**
A. 이전 단계 확인: 사용자가 지나온 길을 다시 확인 하고 싶어 '이전' 버튼을 누르거나 반대로 스와이프할 경우, 시스템은 직전 노드의 사진과 안내 데이터를 다시 렌더링한다.
B-1. 시스템이 경로 데이터를 불러올 수 없다면 일정한 횟수로 반복 시도하고 그래도 불가하면 오류 메시지를 디스플레이한다.
B-2. 사용자는 오류 메시지를 인식하고 유스케이스를 마친다.

**종료 조건 :** 사용자가 목적지에 도착한다.
